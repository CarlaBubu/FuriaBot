Olá! Esse é o FURIAbot, um desafio dado pela FURIA para o processo seletivo para a vaga de Assistente de Engenharia de Software na FURIA. Para rodar o programa, é necessário ter VSCode ou qualquer outro software de desenvolvimento web instalado. Os Requisitos Funcionais e as funcionalidades (até então) do site são:

RF1: Fazer cadastro no chatbot Fúria;
RF2: Fazer login no chatbot Furia;
RF3: Exibir mensagem assim que o usuário abre o site do bot;
RF4: Responder mostrando as notícias mais recentes de forma aleátoria quando o usuário pede o comando de mensagens;
RF5: Responder mostrando os jogadores de cada time quando o usuário solicitar;
RF6: Responder mostrando as curiosidades de forma aleatória quando o usuário solicitar;
RF7: Responder mostrando o @ de todas as redes sociais quando o usuário solicitar redes sociais, instagram, twitter ou youtube;
RF8: Responder com link do site da Fúria quando o usuário solicitar pelos produtos;
RF9: Encaminhar usuário para página do quiz quando for solicitado o quiz;
RF10: Lançar frases de impacto dos jogadores de modo aleatório;

Porém, nem todos os RF foram possíveis serem implementados, por questão de tempo e falta de recursos para instalar mais alguns softwares necessários. Então os trabalhos futuros, a qual eu gostaria de implementar ainda, são:

1 - Integrar o site a um banco de dados onde irá armazenar todas as curiosidades, jogadores, times e diversos dados
2 - Integrar o bot em uma API para atualizar de forma automática as notícias;
3 - Fazer cadastro no chatbot Fúria;
4 - Fazer login no chatbot Furia;
5 - Lançar frases de impacto dos jogadores de modo aleatório (durante a conversa com o chat).

Obrigada a todos pela atenção e oportunidade de fazer parte desse processo seletivo nessa equipe incrível!
